# Mizo Booking App - React Native

## Install dan
1. Node.js install rawh: https://nodejs.org
2. Terminal-ah: npm install -g expo-cli
3. He folder-ah hian: npm install
4. Run na: npx expo start

## APK siam dan
1. expo login
2. eas build -p android
3. APK download link i hmu ang

## Firebase Setup
1. https://console.firebase.google.com ah kal rawh
2. Project thar siam rawh: mizo-booking-app
3. firebase.js ah config thlak rawh
4. Firestore Database enable rawh

## Play Store dah dan
1. Google Play Console account siam - $25 one-time
2. APK upload la, screenshot 3+ dah rawh
3. Description Mizo tawngin ziak rawh
4. Review nghak - ni 3-7 chhung
